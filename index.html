what is ArctineOS?

an arch-based distro designed for simplicity and ease of use, with sane defaults.

it is made to be familiar for newcomers wanting to use an arch-based OS, and is designed to be a distro where not a lot of maintenance is required.

snapshots

on every update or new installed package, a snapshot is created so you can roll/boot back into a previous system state in case anything goes wrong.

customised desktop

ArctineOS comes with a customised version of GNOME meant to be familiar to Windows users switching to it, while attempting to improve UX.
